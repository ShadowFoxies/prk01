## Завдання

### 1. Архітектура пакету та ієрархія класів

Спроєктувати модульну архітектуру пакету `cluster_monitor` за стандартом PEP 8 із регламентацією публічного інтерфейсу через `__all__`. Реалізувати базовий клас метрик `BaseNodeMetric`, спеціалізовані класи `ComputeNode` і `StorageNode` з міксином `AlertableMixin`, а також ієрархію власних винятків (`CorruptedLogRecordError`, `InvalidBitmaskError`, `StorageSubsystemError`).

### 2. Потоковий парсинг, бітова діагностика та відмовостійке збереження

Розробити регулярний вираз з іменованими групами `LOG_LINE_PATTERN` та генератор `stream_log_records` для потокового читання журналу без завантаження файлу в пам'ять. Реалізувати побітову перевірку прапорів регістру `HealthFlag`, інкапсуляцію через `@property`, dunder-методи (`__str__`, `__repr__`, `__eq__`, `__hash__`), розширені сигнатури функцій фільтрації (`*args`, keyword-only, `**kwargs`) та безпечне збереження дампу через контекстний менеджер `IncidentDumpWriter` і `try-except-else-finally`.

### 3. Обґрунтування рішень у межах моделі CPython

Проаналізувати асимптотичну складність обраних структур даних (`O(1)` проти `O(n)`) та механізм `compact dict`, керування пам'яттю (`ob_refcnt`, Generational GC, інтернування об'єктів), C3-лінеаризацію `MRO` у схемі з міксином, роботу NFA-рушія регулярних виразів без *catastrophic backtracking*, а також реалізацію ідіоми RAII через `__enter__`/`__exit__`.
